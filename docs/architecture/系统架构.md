# 系统架构

## 服务与数据

| 服务 | 职责 | 默认宿主机端口 |
| --- | --- | --- |
| frontend | Nginx 提供 React 页面和 API 反向代理 | 3000 |
| backend | FastAPI、鉴权、问答、后台导入任务 | 8000 |
| mysql | 账户、会话、知识库、文档与分块、导入任务、问答历史、收藏 | 3306 |
| milvus | 分块向量及检索过滤字段 | 19530、9091 |
| etcd | Milvus 元数据 | 容器网络内 |
| minio | Milvus 对象数据 | 9000、19001 |

Compose 按依赖与健康检查启动服务，容器通过服务名访问，宿主机默认仅绑定回环地址。数据库和索引使用命名卷，日常关闭用 `docker compose down`。原文目录 `data/raw/` 只读挂载，上传文件和导入产物保存在 `data/processed/`。备份时需一并保留原文、上传文件和数据库卷。启动与配置入口见 [README](../../README.md)。

后端的 `api/v1` 提供 HTTP 路由，`domain` 定义核心对象，`services` 编排业务，`repositories` 负责访问 MySQL 与 Milvus，`workers` 提供离线导入、诊断和评测。文档、现行版本与分块通过稳定 ID 关联。

## 鉴权与权限

- 匿名可登录、注册、刷新会话并访问健康检查。
- 登录后可查看知识库和文档、问答，并管理自己的历史与收藏。管理员可创建及编辑知识库、上传或删除文档、查询和重试导入任务。
- Access Token 保存在前端内存中，有效期 15 分钟。Refresh Token 经 HttpOnly Cookie 传递，有效期 7 天，数据库保存摘要。刷新轮换凭据，退出撤销会话。
- 原文读取使用 2 分钟的单文档票据，支持 Range 请求。通用鉴权拒绝该票据，原文路由关闭请求日志。
- API 契约和当前接口边界见 [系统接口](../api/系统接口.md)。

## 文档导入

管理员分别通过单文件和批量上传接口提交文件。后端保存原文并创建独立任务，单个后台线程串行消费，前端可按任务 ID 轮询。批量上传的校验和任务创建整批提交，异步解析结果按文件分别记录。工作线程使用索引写入返回的文档 ID 更新任务，去重时返回已有文档 ID。

原生解析支持 TXT、Markdown、DOCX 及 PDF。图片走 OCR，PDF 按页提取文字，空文字页可用 PaddleOCR。DOC、WPS、复杂表格专项解析和 PDF 文字坐标目前缺少支持。离线命令批量处理本地 TXT/PDF，通过 `--ocr` 开启空文字页识别。

导入按知识库和文件 SHA-256 去重。MySQL 连接锁覆盖查重与写入，分块及向量保存同一组稳定 ID。需要重建索引时使用原保留路径，规则见 [文档去重](../testing/文档内容去重.md)。

## 在线问答

1. 根据知识库、制度状态和时间条件，并行查询 MySQL ngram 全文索引与 Milvus BGE 向量索引。编排层再校验返回结果的有效状态，单路失效时可用另一通道继续检索。
2. RRF 按分块 ID 合并候选。保留部分双通道共识，再按向量加权排名与问题短语在正文中的覆盖率选择证据。默认最多 12 块，总预算 12,000 字符。
3. 通过 LangChain 的 ChatDeepSeek 适配器发送问题和带标签的文本证据。上下文为空时直接返回依据不足。
4. SSE 逐步发送正文，最终校验 JSON 和引用后保存历史并返回 `done`。证据支持度衡量已引用证据的支持程度。非流式入口用于评测及兼容调用。

见 [流式契约](../api/流式问答.md)、[排序验证](../testing/RAG融合排序与上下文对照.md)和 [架构决策](../adr/README.md)。
