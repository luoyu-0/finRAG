## 约定

- 文件名：`<四位编号>-<简短标题>.md`，编号连续递增。
- 模板：状态 / 日期 / 决策者 / 相关文档，随后为背景、决策、考虑的替代方案、后果。
- 状态取值：`提议`、`已接受`、`已取代`、`已废弃`。
- 新增或变更 ADR 时同步更新上表。
- 计划或实现与现有 ADR 冲突时，**不得静默覆盖**，应明确指出冲突并重新评审。
- ADR 记录决策当时的信息。若后续情况变化，应新增一篇 ADR 标注为「已取代」，而不是直接改写历史记录。
