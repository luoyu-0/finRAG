# 文档正文与知识库列表体验优化

## 背景

文档正文页此前把 PDF 与 TXT 一视同仁：PDF 只把命中分块按「页 + 条号」重排后渲染成文本卡片，读者看不到版面，也无法像浏览器那样翻页；`blocks` 内同一页的未标注条号分块顺序还会随分块 ID 变化。知识库详情页的页码、筛选条件保存在组件状态里，进入文档页再返回就回到第一页；每次换页或删除都会把整块界面替换成加载态。知识库创建之后没有修改名称与描述的入口。

## 改动

1. **返回保留位置**：列表页码与筛选条件（`page`/`sort`/`order`/`category`/`format`/`warning`/`q`）写入 URL；文档标题链接带上 `kb` 与 `back` 查询串，正文页的「返回知识库」原样带回，浏览器后退也回到原页。从问答角标进入时，返回链接携带来源文档 ID。
2. **局部刷新**：详情页拆成页头、`StatsSection`、`DocumentRow` 等 `memo` 组件，元信息与文档列表分别加载；`useLoader` 新增 `keepData` 与 `setData`，换页时保留旧表格并只显示「更新中…」，失败时给出可重试的行内提示；历史页删除、收藏页取消收藏改为就地更新，不再整页重刷。知识库列表分页同样改为局部更新。
3. **PDF 页面内渲染**：新增 `POST /documents/{id}/file-ticket`（2 分钟、单文档票据）与 `GET /documents/{id}/file`（`inline`、支持 `Range`），正文页用 pdf.js 把原文件渲染到画布，打开即定位到引用页，并提供翻页、缩放、页码跳转与「新标签打开」。
   先前的 `iframe` 方案依赖浏览器内置 PDF 阅读器：窄窗口、企业策略禁用内置阅读器或扫描页绘制失败时只剩一块空白，前端既无法感知失败也没有替代路径，因此改为页面内渲染。
4. **不再只渲染分块**：`DocumentContent` 新增 `has_file`；存在 PDF 原文时展示整篇 PDF。原文缺失、换票或渲染失败时显示已有分块，重试会重新换票。
5. **面包屑**：新增 `Breadcrumb` 组件，正文页与知识库详情页顶部显示「知识库 › 当前库 › 当前文档」，每一级可点击回退。
6. **知识库信息可编辑**：详情页新增「编辑信息」，管理员可修改名称与描述（契约 §7.4 的 `PATCH`），保存后就地更新页头，不重新请求整页。
7. **导航滑动高亮**：主导航使用一块独立的 `.app-nav__indicator` 底色，切换栏目时从旧位置移到新位置，宽度/高度跟随目标项，落位带约 3% 过冲的轻微回弹；文字本身不参与动画。窄窗口下 5 个栏目等宽（`flex: 1 1 0`），选中项加粗且不显示下划线（覆盖 `base.css` 的 `a:hover` 下划线与深蓝色）；同时修正了窄窗口侧栏被网格拉伸、页面顶部留白的问题。

## 接口与数据影响

- 新增原文票据与文件接口，字段与错误码见 [系统接口](../api/系统接口.md) §8.3.2；`DocumentContent` 增加 `has_file`。
- 未改动数据库结构，未重新导入或重建索引。票据不落库，只依赖现有 `JWT_SECRET_KEY` 签发与校验。

## 验证

- 后端：`pytest tests/integration/test_page_api.py` 3 项通过，包含票据签发、无票据 401、票据指向其他文档 403、原文缺失 404。
- 前端：`npm run lint`、`npm run typecheck`、`npm run format:check` 通过；`npm run test` 20 个文件 119 项通过，新增用例覆盖换页不整页重刷、标题链接回传、失败保留表格、PDF 按页定位、手动跳页、面包屑与返回位置、描述编辑。
- 接口实测：`file-ticket` 返回 2 分钟票据；`GET /documents/{id}/file` 返回 `200 application/pdf`、`Content-Disposition: inline`、`Accept-Ranges: bytes`，`Range: bytes=0-1023` 返回 `206`；无票据返回 `401 AUTH_FILE_TICKET_INVALID`。
- 浏览器实测（Playwright + Edge，6 项全部通过）：713 px 窄窗口下 8 页 OCR 扫描件能画出内容（画布 611×864，深色像素 18165）；打开定位第 1 页、阅读器内翻页到第 2 页、页码跳转到第 4 页；260 页报告按引用定位到第 2 页；放大后画布由 1046 变为 1307 像素。知识库详情换页时页头与统计保持显示，返回仍在第 3 页。

## 已知限制

- PDF 内无法按字符区间高亮被引条文（分块未保存版面坐标），定位到页并在上方展示条文摘录；条文级高亮需要导入阶段保存 bbox。
- 票据有效期 120 秒。仍需向服务端读取 PDF 范围时，票据过期会触发摘录降级，可重新签票重试。
- pdf.js 的 worker 是 `.mjs`，Nginx 默认 MIME 表不识别该扩展名，曾导致 worker 以 `application/octet-stream` 返回、阅读器只能退回假 worker 并报错；已在 `infra/nginx/default.conf` 为 `.mjs` 显式声明 `application/javascript`。
- 列表排序与分类筛选仍依赖尚未实现的 §7.6/§8.2 后端参数，界面对应控件保持禁用并给出说明。
