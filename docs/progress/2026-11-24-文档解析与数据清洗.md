# 文档解析与数据清洗

日期：2026-11-24。

本轮针对离线导入的 PDF 解析质量问题做了生产链路改造，并清理了不属于制度知识库的财务报表类文档。

## 解析规则

- PDF 从 pypdf 逐页 `extract_text` 改为 PyMuPDF 文本块和表格提取，保留行坐标用于版面判断。
- 跨页重复出现的短行、页码在页眉/页脚区域被移除；正文中相同文字不受影响。
- 上一页末段没有句末标点、下一页不是新章/条/附件时，拼接为同一自然段；替换页首继续沿用上一页条号，遇到新章标题则停止继承。
- 文字型 PDF 的表格转换为 `列 | 列 | 列` 行文本，表格区域内的文本块不再重复计入正文；只有一行的“封面标题表格”不转换。
- OCR 渲染从 150 DPI 提高到 220 DPI，开启行方向分类，并记录平均置信度和文字过少告警。
- 解析版本从 `native-v1` 升到 `native-v2`，已有索引需 `--rebuild` 才会使用新规则。

## 数据范围

- 新增文件名过滤：部门决算、部门预算、财务报表、审计报告等默认不导入；`--include-excluded` 可强制保留。
- `data/raw/_excluded/` 等隔离目录不扫描。
- 已把 13 份人民银行部门决算/预算 PDF 移到 `data/raw/_excluded/financial_statements/`，未直接删除，便于回退。
- 新增 `app.workers.prune_off_topic`，用于预览或删除已入库的财务报表类索引；默认只预览，不删除原文件。

## 验证

- 新增版式、过滤、OCR 坐标和真实 PDF 合成用例，`pytest tests/unit/test_pdf_layout.py tests/unit/test_native_import.py tests/unit/test_ocr_provider.py` 共 34 项通过。
- 真实样本检查了跨页拼接、表格行、页眉页脚清理和长文档解析耗时；全量 PDF 回归结果见 [文档解析与数据清洗](../testing/文档解析与数据清洗.md)。
- 尚未重建 Docker 容器和 MySQL/Milvus 索引；新规则需要通过 `docker compose run --rm --no-deps backend python -m app.workers.import_documents --rebuild`（扫描件再加 `--ocr`）才能体现在在线问答中。
