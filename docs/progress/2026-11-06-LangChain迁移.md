# LangChain 在线问答迁移

用户确认项目使用 LangChain，并授权安装所需依赖。本轮将在线 RAG 流程接入 LCEL，将 DeepSeek HTTP 请求替换为官方异步 ChatDeepSeek；保留领域对象、Repository、过滤、融合、引用与错误契约。无需为框架迁移重新分块或导入数据。

已完成 61 项后端测试，RAG 模块覆盖率 85%，依赖检查通过；新镜像构建、启动和 HTTP 问答冒烟通过。

已完成 506 份 TXT、161 份 PDF 的全量导入检查（含选择性 OCR）。新增同知识库内按文件字节 SHA-256 去重，文件名不参与重复判定；通过 MySQL 锁串行化同知识库导入与清理。经用户授权清理已有 17 份重复索引，保留 raw 原文件。最终入库 443 份唯一文档、10,914 个分块，MySQL/Milvus 的完整分块 ID 集合一致；再次导入 667 份全部跳过、0 失败。1 份 WPS 暂不处理，83 页 OCR 无可用文字尚待人工核对。

50 题真实评测完成，49 题成功、1 题因 JSON 解析失败。成功题目来源命中率 98.0%、条文命中率 71.4%、平均字面相似度 33.0%；这些指标不代表答案正确率，也没有同索引迁移前基线可用于质量提升比较。首次完整报告已保留。详细步骤、报告路径与限制见 [迁移验证](../testing/LangChain迁移验证.md) 和 [内容去重说明](../testing/文档内容去重.md)。

本轮不修改前端，不新增知识库等未实现接口。实现与验证完成后，按用户要求分项提交并推送分支，发起合并到 main 的 PR；真实评测的偶发格式失败作为已知限制保留记录。
