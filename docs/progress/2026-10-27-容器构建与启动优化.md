# 容器构建与启动优化

日期：2026-10-27。

## 完成内容

- 保留 PaddleOCR/OpenCV 依赖的 Debian 系统库，调整 Compose 默认软件源并允许通过 `.env` 覆盖。
- 使 `apt-get update` 在任一软件源失败时中止构建，避免软件包索引下载失败后继续执行。
- Windows 启动脚本默认复用已有镜像；首次构建或代码、依赖变更时使用 `./scripts/start.ps1 -Build`。
- 同步 README、系统架构说明及[耗时回归记录](../testing/容器构建耗时回归.md)。

## 验证与后续
