# Triage 标签

工程技能使用五种标准 triage 角色。下表定义这些角色在本仓库 Issue Tracker 中对应的标签。

| 标准角色 | 仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已明确，可交给 Agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 确认不处理 |

当技能提及某种 triage 角色时，使用表中对应的仓库标签。
