# 知识库分页与筛选验证

## 覆盖范围

`backend/tests/integration/test_document_query.py` 通过 FastAPI 的真实请求入口验证以下行为。

- 四种排序字段的升降序，先排序再跨页截取，同值按文档 ID 稳定排序。
- 分块数为零的文档、分类缺失、上传路径、目录名包含分类前缀。
- 分类、格式、标题和有效状态组合筛选，大小写扩展名与搜索转义。
- 有告警、无告警筛选，空字符串和带空白的空 JSON 数组。
- 分类聚合的库隔离、空库、缺失库和未登录请求。
- 分页总数、末页、越界页和非法参数的 422 响应。

## 运行方式

在安装了项目现有后端开发依赖的环境中，从 `backend` 目录执行 `python -m pytest -q`。设置 `DEEPSEEK_API_KEY` 为空字符串，避免本地 `.env` 让测试初始化真实检索服务。

## 2026-11-18 实测

- 后端全量测试 75 项通过。使用已有容器依赖及本地 pytest，隔离网络运行。
- 真实 MySQL 中 443 份文档汇总为 23 个分类，49 份含解析告警。分类与格式计数均与原始元数据逐条统计一致，四种排序方向及跨页查询通过。
- 经前端 Nginx 转发执行真实登录及 API 请求，每页 50 条时第一页返回 50 条，第 9 页返回 43 条且 `has_next=false`；分类与 TXT 格式组合筛选返回 58 条；非法排序字段返回 422。
- `docker compose up -d --build --wait --wait-timeout 180 backend frontend` 成功，容器健康检查通过。

本次验证覆盖 SQLite 回归与 MySQL、HTTP 链路，浏览器控件逐项点击尚未执行。
