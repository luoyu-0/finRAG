## 数据初始化和限制

后端启动时对 MySQL 执行 `create_all`，只创建缺失的 `users`、`user_sessions`、`qa_history` 表；已有表与数据不会被删除或重建。空用户库要求设置 `ADMIN_BOOTSTRAP_PASSWORD`，创建管理员后即使移除该变量也不会重置密码。今后若修改现有表字段，仍需单独迁移脚本。

当前只对接前端已启用的登录与问答页面。用户管理、历史列表、收藏、知识库和文档导入接口仍待实现。成功的问答会写入 `qa_history`，但由于真实检索服务尚未接入，当前正常部署不会产生成功问答。登录失败限速采用单进程内存计数；多实例部署前应替换为共享限速存储。
