# 关键场景测试

| 场景 | 自动化断言 | 用例 |
| --- | --- | --- |
| 登录与隔离 | 登录、刷新、退出，拒绝读取其他账户的问答和未授权的管理操作 | [鉴权与问答](../../backend/tests/integration/test_auth_qa_api.py)、[页面接口](../../backend/tests/integration/test_page_api.py) |
| 单文件和批量导入 | 批次预校验、按输入顺序入队。任务首试成功、相同内容复用文档、失败项可以独立重试 | [批量 API](../../backend/tests/integration/test_page_api.py)、[后台任务](../../backend/tests/integration/test_document_deduplication.py) |
| 混合检索与证据 | 过滤失效制度、提升判别性短语命中、单路故障降级、无证据拒答 | [RAG 单元测试](../../backend/tests/unit/test_rag_core.py)、[100 题开发回归](RAG融合排序与上下文对照.md) |
| 流式失败与恢复 | API 仅在完成后保存历史。浏览器处理正文之后的错误事件，重试后能打开引用原文并高亮段落 | [流式接口](../../backend/tests/integration/test_stream_qa_api.py)、[浏览器回归](../../frontend/tests/e2e/qa-retry-citation.spec.ts) |
| 文档阅读与溯源 | 原文票据限于单文档。PDF 加载失败时显示摘录，返回知识库时保留来源定位 | [原文访问](../../backend/tests/integration/test_page_api.py)、[正文页测试](../../frontend/tests/unit/document-content-page.test.tsx) |
| 解析与数据范围 | 页眉页脚和页码清理、跨页段落拼接、表格行解析、财务报表排除 | [解析清洗](文档解析与数据清洗.md)、[版式测试](../../backend/tests/unit/test_pdf_layout.py) |

后端在 `backend/` 安装 `requirements-dev.txt` 后执行 `python -m pytest`。导入任务用例使用 SQLite、真实文本解析和内存向量替身。实际 MySQL 和 Milvus 的导入验证见 [批量导入记录](现有数据批量导入与问答回归.md)。

浏览器测试在 `frontend/` 安装依赖及 Chromium 后执行 `npm run test:e2e -- qa-retry-citation.spec.ts`。默认访问 `http://127.0.0.1:3000`，可通过 `PLAYWRIGHT_BASE_URL` 指定前端地址。用例拦截会话、SSE 和原文请求，可用普通 Vite 开发服务运行。全套 E2E 还包含使用真实账户和反向代理的 [容器冒烟](../../frontend/tests/e2e/smoke.spec.ts)，其 CI 运行条件见 [工作流](../../.github/workflows/ci.yml)。

自动化用例使用固定模型响应或生成替身。真实模型效果通过开发集评测，最终验收集独立维护。
