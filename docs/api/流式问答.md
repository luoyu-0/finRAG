# 流式问答接口

## POST /api/v1/qa/answer/stream

鉴权、请求体与 `/api/v1/qa/answer` 相同。原非流式接口继续用于评测及兼容调用。真实问答页改用此接口。

成功建立连接后返回 `Content-Type: text/event-stream`，禁用代理缓冲与缓存。UTF-8 SSE 事件以空行分隔，`data` 为单行 JSON：

```text
event: delta
data: {"text":"### 结论\n\n"}

event: delta
data: {"text":"机构应依法履行义务。[S1]"}

event: done
data: {"answer":"完整 Markdown", "citations":[], "evidence_support":{}, "warnings":[], "trace_id":"..."}
```

`done` 数据结构为现有 `QuestionResponse`，示例省略引用及支持度内部字段。只有收到 `done` 才算成功，最终正文以 `done.answer` 为准；生成过程中正文尚未经过完整 JSON 和引用校验，前端标明“生成中”，不展示最终支持度。

连接建立前的鉴权、参数与配置错误沿用 HTTP 401/403/422/503。连接建立后的检索、生成或保存失败发送 `error` 事件，字段为 `error_code`、`message`，然后结束。中断或 error 不保存成功历史，前端清除不完整答案并显示失败；断流且没有 done 同样视为失败。生成部分开始后不自动重试，避免拼接两个回答。

```text
event: error
data: {"error_code":"RAG_GENERATION_FAILED","message":"回答生成失败，请重试"}
```

首字延迟从客户端发起请求计时至收到首个非空答案正文增量；标题或状态事件不能用来证明实质答案在 2 秒内出现。2 秒是实测目标，远程模型和网络波动可能超时；不通过占位文本伪造达标。前端流读取支持取消与超时，Nginx 不缓冲 SSE。
